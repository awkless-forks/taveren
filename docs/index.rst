Ta'veren
========

Ta'veren is a static analysis framework that recovers finite state machines
(FSMs) from PLC binaries and verifies safety policies against them to discover
blind-trust vulnerabilities (BTVs) in PLC programs.

It is described in the paper `Discovering Blind-Trust Vulnerabilities in PLC
Programs via Finite State Machine Recovery
<https://bonnie1256.github.io/files/taveren.pdf>`_ (NDSS 2026).
